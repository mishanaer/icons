# Паспорт стиля иконок

Этот документ фиксирует визуальный язык `mishanaer/icons` для создания новых иконок с нуля. Правила получены из анализа всех 760 исходных иконок варианта `round/line`; геометрические показатели дополнительно проверены на 207 иконках, уже восстановленных как редактируемый stroke-SVG.

## Характер стиля

Иконки геометричные, компактные и дружелюбные. Силуэт должен считываться в размере 24×24 без декоративного шума. Скруглённые торцы и стыки смягчают строгую сетку, но сама конструкция остаётся простой: сначала линии, окружности, дуги и скруглённые прямоугольники, затем — минимально необходимое число кривых.

Главный критерий: новая иконка должна выглядеть частью семейства в размере 24 px, а не просто быть технически похожим SVG.

## Обязательные токены

| Параметр | Значение |
|---|---:|
| Координатная система | `viewBox="0 0 24 24"` |
| Основная толщина | `stroke-width="2"` |
| Цвет | `currentColor` |
| Торцы | `stroke-linecap="round"` |
| Стыки | `stroke-linejoin="round"` |
| Основная заливка | `fill="none"` |
| Основной центр | `(12, 12)` |
| Основная сетка | 1 единица |
| Дополнительная сетка | 0,5 единицы |
| Допустимая точная подстройка кривых | 0,25 единицы или меньше, только после оптической проверки |

Минимальный каркас файла:

```svg
<svg xmlns="http://www.w3.org/2000/svg"
     width="24" height="24" viewBox="0 0 24 24"
     fill="none" stroke="currentColor" stroke-width="2"
     stroke-linecap="round" stroke-linejoin="round">
  <!-- Простые семантические примитивы -->
</svg>
```

Залитые элементы допустимы только как самостоятельные смысловые точки или компактные центры. Их нельзя использовать для имитации контура.

## Сетка и оптические границы

- Начинать построение с координат `3`, `12`, `21`: это самые частые опорные значения набора.
- 70% опорных координат восстановленных иконок попадают на сетку 0,5; 54% — на целые координаты. Произвольные дроби не являются базовым языком стиля.
- 77% прямых принадлежат направлениям 0°, 45°, 90° или 135°. Другие углы допустимы для предметных и органических силуэтов.
- У 92% каталога визуальный центр ограничивающей рамки расположен не дальше 0,5 единицы от `(12, 12)`.
- Типичная видимая рамка занимает около `20,5 × 20,4` единицы. Для обычной иконки начинать с видимой области примерно `2…22`.
- Для открытой линии с круглыми торцами удобная базовая ось — `3…21`: контур толщиной 2 визуально занимает `2…22`.
- Контейнерные окружности и квадраты могут доходить видимым контуром примерно до `1…23`.
- Стрелки, диагональные перечёркивания и жесты могут доходить до `0…24`, если это нужно смыслу. Это исключение, а не стандартный отступ.

Центрировать нужно оптически. Асимметричный объект может быть математически сдвинут, если при 24 px он выглядит устойчивее рядом с родственными иконками.

## Геометрический словарь

Выбирать модель в таком порядке:

1. `line`, `polyline` или `polygon` для прямых конструкций.
2. `circle` для кругов и круглых контейнеров.
3. `arc` для частей окружности.
4. `rect` с `rx` для скруглённых контейнеров.
5. `ellipse` для овальных деталей.
6. Кубическая кривая только для формы, которую нельзя честно выразить предыдущими примитивами.

Нельзя заменять окружность многоугольником, прямую — цепочкой почти прямых отрезков, а простой угол — набором случайных Bézier-точек.

Измеренный ориентир сложности для восстановленных иконок:

- медиана — 3 графических элемента и 4 смысловых сегмента;
- 90-й перцентиль — 6 элементов и примерно 10 сегментов;
- медианное число кубических сегментов — 0;
- наиболее частые малые радиусы — `1`, `1.2–1.3`, `1.5`, `2`, `3`;
- типовые крупные радиусы — `5`, `6`, `8.5`, `10`, `12.5`.

Это ориентиры, а не квоты. Сложная иконка может потребовать больше деталей, но каждый дополнительный узел должен менять силуэт или смысл.

## Пропорции и детали

- Сначала строится внешний силуэт, затем главная внутренняя деталь, затем вторичные детали.
- Внутренняя деталь не должна конкурировать по визуальному весу с силуэтом.
- Симметричные формы строятся от общей оси или общего центра; зеркальные части не подгоняются независимо.
- Повторяющиеся элементы используют общий радиус, шаг и семейство углов.
- Пересекающиеся линии должны сходиться в одной геометрической точке. Нельзя скрывать разрыв толщиной контура.
- Круглые торцы создаются `stroke-linecap`, а не дополнительными окружностями.
- Скруглённый прямоугольник создаётся `rect rx`, а не многоугольником из множества точек.
- Органические формы строятся несколькими плавными кривыми с непрерывной касательной. Микроизломы и волнистая пиксельная трассировка запрещены.

## Семейства для сравнения

Перед рисованием новой иконки выбрать 3–5 ближайших референсов из каталога:

- базовая геометрия: `circle`, `square`, `triangle`, `star`, `check`, `x`;
- направления: `arrow-*`, `arrows-*`, `chevron-*`, `end-point-*`;
- контейнеры: `plus-circle`, `check-square`, `arrow-circle-*`, `arrow-square-*`;
- интерфейсные объекты: `calendar`, `camera`, `bell`, `file`, `folder`;
- предметные формы: `alarm-clock`, `anchor`, `bank`, `bike`, `home`, `map`;
- органические формы: `acorn`, `apple`, `cat`, `hand`, `person`.

Новая иконка должна наследовать пропорции от ближайшего семейства, а не усреднять весь каталог.

## Порядок создания новой иконки

1. Определить один главный смысл и выбрать соседнее семейство.
2. Нарисовать силуэт на сетке 24×24 примитивами с контуром 2.
3. Добавить только необходимые внутренние детали.
4. Удалить точки и сегменты, которые не меняют форму при 24 px.
5. Сравнить иконку рядом с 3–5 референсами при одинаковом размере.
6. Проверить оптический центр, вес четырёх сторон и просветы.
7. Проверить рендер с толщиной 1, 2 и 3: детали не должны исчезать, сливаться или разрываться.
8. Экспортировать семантические примитивы без масок, скрытых объектов и лишних `transform`.

## Приёмка

Новая иконка готова, если одновременно выполняются условия:

- узнаваема без подписи в размере 24×24;
- визуально совпадает по весу с ближайшими иконками;
- использует контур 2, круглые торцы и круглые стыки;
- не обрезается внутри `viewBox`;
- сохраняет топологию при толщине 1, 2 и 3;
- состоит из минимального разумного числа примитивов и узлов;
- не содержит сторонней геометрии из других библиотек;
- после экспорта остаётся редактируемым stroke-SVG, кроме осознанных залитых точек.

## Основание анализа

- Проанализировано: 760 из 760 точных исходных иконок `round/line`.
- Все используют `viewBox 0 0 24 24`.
- Медианная площадь чёрного контура при рендере — 26% контейнера.
- Визуальная рамка измерена на точных рендерах 384×384 и пересчитана в координаты 24×24.
- Геометрический словарь и частоты примитивов измерены на 207 редактируемых stroke/mixed SVG.
- Остальные 553 точных expanded-outline SVG использованы для анализа внешнего вида, но не как образец количества узлов.

Полный машинно-читаемый срез измерений находится в [`style-profile.json`](./style-profile.json).
