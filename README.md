# Icons

Каталог из 760 собственных SVG-иконок. Поиск открывается кнопкой или сочетанием `⌘ K` / `Ctrl K`, а клик по иконке скачивает её SVG-файл.

Сейчас 207 иконок собраны как редактируемые stroke-SVG с контуром 2 px. Остальные 553 точно повторяют исходный вид, но пока хранятся как fixed outline.

## Локальный запуск

Каталог загружает JSON-манифест, поэтому его нужно открывать через локальный HTTP-сервер:

```bash
python3 -m http.server 8088
```

Затем открой [http://127.0.0.1:8088/](http://127.0.0.1:8088/).

## GitHub Pages

Каталог публикуется из ветки `main`, корня репозитория, и доступен по адресу [mishanaer.github.io/icons](https://mishanaer.github.io/icons/).

Все 760 иконок каталога — собственная геометрия. Lucide используется только для двух служебных пиктограм интерфейса: поиска и закрытия окна.
