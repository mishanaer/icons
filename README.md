# Icons

Каталог из 760 собственных SVG-иконок в двух вариантах: `Stroke` и `Filled`. Переключатель находится в шапке, поиск открывается кнопкой или сочетанием `⌘ K` / `Ctrl K`, а клик по иконке скачивает выбранный SVG-вариант.

Stroke-вариант сохраняет текущий набор из 760 иконок. Filled-вариант содержит точные `round/solid` SVG для тех же 760 названий.

## Локальный запуск

Каталог загружает JSON-манифест, поэтому его нужно открывать через локальный HTTP-сервер:

```bash
python3 -m http.server 8088
```

Затем открой [http://127.0.0.1:8088/](http://127.0.0.1:8088/).

## GitHub Pages

Каталог публикуется из ветки `main`, корня репозитория, и доступен по адресу [mishanaer.github.io/icons](https://mishanaer.github.io/icons/).

Production-витрина также доступна на [mishanaer-icons.vercel.app](https://mishanaer-icons.vercel.app/).

Все 760 иконок каталога — собственная геометрия. Lucide используется только для двух служебных пиктограм интерфейса: поиска и закрытия окна.
