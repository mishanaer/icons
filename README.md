# Icons

Минималистичный каталог SVG-иконок.

Открой `index.html` локально или опубликуй содержимое через GitHub Pages. В каталоге 760 SVG-иконок, поиск открывается кнопкой или сочетанием `⌘ K`, а клик по иконке скачивает её SVG-файл.

Правила создания новых иконок зафиксированы в [паспорте стиля](./STYLE_GUIDE.md).
